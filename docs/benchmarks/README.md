## 复测规则

1. 使用 `REG-001` 中完全相同的用户输入和验收 Oracle。
2. TOE-DAC 从用户消息写入时间计时，到最终可见报告写入时间停止。
3. 直接流程必须真实访问网页、提取标题与正文并保存截图；只把既有事实交给模型不算完整对照。
4. 模型生成至少运行 3 次，报告每次结果、区间和中位数。
5. 同时记录墙钟时间、模型/工具分布、Token、重试、修复、人工介入、终态和产物完整性。
6. 模型、工具版本、机器或网络环境变化必须写入环境信息，不与旧结果静默混合。
