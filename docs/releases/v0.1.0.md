# TD Agent v0.1.0 — TOE-DAC 原型

> 首个交互式概念验证版本，验证长周期 Agent 任务的持久化控制协议和异常恢复路径。

## 已验证能力

| 领域 | 能力 |
| --- | --- |
| 任务模型 | User Thread、Session 和分层 TD 实例 |
| 控制流程 | Target → Observe → Estimate → Decide → Act → Check |
| 目标治理 | Target 校验、自动修补、预算限制和人工升级 |
| 结果检查 | 区分 Action Check 与 Target Check |
| 异常经验 | 记录异常、处理方式、成功和失败结果 |
| 可追溯性 | 状态、事件、操作和产物持久化 |
| 验证方式 | Mock/Live E2E 场景与 Rich 交互终端 |

## 兼容性

这是历史原型快照，包含私有本地 `andy-state` 依赖，不能从公开仓库独立安装。实际使用请从 `v0.2.0` 或更高版本开始。
