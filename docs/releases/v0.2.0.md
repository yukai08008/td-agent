# TD Agent v0.2.0 — 公开独立安装

> 本版本把内部原型整理为可以从公开 GitHub 仓库独立安装、配置和更新的 CLI。

## 主要变化

| 类型 | 变化 | 用户价值 |
| --- | --- | --- |
| 新增 | Linux/macOS 一行安装、更新和卸载 | 无需手工准备 Python 环境 |
| 新增 | 中文文档、版本显示和自动更新提示 | 安装和维护路径更清晰 |
| 新增 | `~/.config/td-agent/` 机器配置目录 | API Key 与代码仓库分离 |
| 新增 | `~/.local/share/td-agent/` 默认数据目录 | 多目录启动时仍使用统一数据 |
| 调整 | 内置最小声明式状态机运行时 | 移除私有 `andy-state` 路径依赖 |
| 安全 | `.env.local` 忽略、打包密钥扫描 | 防止模型 API Key 进入 Git 或安装包 |

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/yukai08008/td-agent/v0.2.0/install.sh | bash
```

## 兼容性

- 这是第一个支持从公开仓库独立安装的版本。
- 从 `v0.1.0` 迁移时需要重新安装，不应沿用其本地路径依赖。
