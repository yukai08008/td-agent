# TD Agent v0.3.0 — 指定版本运行

> 本版本增加版本选择能力：默认使用当前安装版本，也可以临时运行或固定安装一个明确的 Git Tag。

## 主要变化

| 类型 | 变化 | 用户价值 |
| --- | --- | --- |
| 新增 | `toe-dac --use-version X.Y.Z` | 临时验证旧版本，不替换当前安装 |
| 新增 | `toe-dac upgrade --version X.Y.Z` | 将本机固定到指定版本 |
| 新增 | 安装脚本接受 `install X.Y.Z` 和 `update X.Y.Z` | 自动化部署可以锁定版本 |
| 安全 | 版本参数只接受规范版本号 | 防止任意 Git 引用或命令注入 |

## 使用示例

```bash
# 临时运行 v0.2.0
toe-dac --use-version 0.2.0 --version

# 固定安装 v0.2.0
toe-dac upgrade --version 0.2.0
```

测试旧版本时建议隔离数据：

```bash
toe-dac --use-version 0.2.0 --data ~/.local/share/td-agent-v0.2 new
```

## 兼容性

- 公开独立运行从 `v0.2.0` 开始。
- `v0.1.0` 使用过私有本地依赖，不能从公开仓库独立安装。
