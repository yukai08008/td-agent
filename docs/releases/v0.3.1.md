# TD Agent v0.3.1 — GitHub-first 版本展示

> 本版本重新组织发布信息：用户从 GitHub 首页、版本索引或 Releases 页面即可清楚了解每个版本的功能变化，不再需要通过 CLI 阅读变更日志。

## 主要变化

| 类型 | 变化 | 用户价值 |
| --- | --- | --- |
| 新增 | README 增加最近版本摘要和 Release 入口 | 打开仓库首页即可了解最新变化 |
| 新增 | 每个版本使用独立、结构化的 Release 文档 | 功能、升级方式和兼容性更容易定位 |
| 调整 | 更新提示直接链接对应 GitHub Release | 更新前可在浏览器查看完整说明 |
| 简化 | 移除 `toe-dac changelog` 命令 | 减少与 Agent 主流程无关的 CLI 功能 |

## 升级

```bash
toe-dac upgrade
```

固定安装本版本：

```bash
toe-dac upgrade --version 0.3.1
```

## 兼容性

- 配置和持久化数据格式与 `v0.3.0` 兼容。
- `toe-dac changelog` 已移除；请访问 [GitHub Releases](https://github.com/yukai08008/td-agent/releases)。
