# TD Agent v0.4.0 — 启动配置引导与可观察安装

> 本版本优化首次使用体验：启动时保证至少有一个真正可用的大模型配置，并让安装过程持续反馈当前阶段和下载进度。

## 主要变化

| 类型 | 变化 | 用户价值 |
| --- | --- | --- |
| 新增 | 启动前检查模型是否启用且 API Key 存在 | 避免进入会话后才发现模型不可用 |
| 新增 | 无可用模型时自动打开交互式配置引导 | 首次启动可以直接完成模型选择和密钥配置 |
| 调整 | `toe-dac config` 成为专门的模型配置管理器 | 集中查看模型状态、配置 Key 和切换默认模型 |
| 调整 | `toe-dac doctor` 同时验证真实模型适配器配置 | 检查结果更接近实际启动条件 |
| 加速 | 默认优先安装 GitHub Release 的预构建 wheel | 避免 Git clone 和本地构建 CLI 包 |
| 可观察 | curl 显示进度、设置连接超时和重试，安装脚本输出阶段 | 网络缓慢时不再长期无反馈 |

## 首次启动

```bash
toe-dac
```

如果没有可用模型，CLI 会自动要求选择模型并输入对应 API Key。密钥仅保存到当前机器的 `~/.config/td-agent/.env.local`。

随时重新进入配置管理：

```bash
toe-dac config
toe-dac config --show
```

## 安装

```bash
curl -fL --connect-timeout 10 --retry 3 --progress-bar \
  https://raw.githubusercontent.com/yukai08008/td-agent/v0.4.0/install.sh | bash
```

## 兼容性

- 配置和持久化数据格式与 `v0.3.1` 兼容。
- 现有 `.env.local` 和 `models.json` 会被保留，不会在升级时覆盖。
