# TD Agent v0.4.1 — 安装依赖收敛

> 本版本针对首次安装速度做根因优化：运行时依赖从 23 个包收敛到与 agenty 相同的轻量级依赖树。

## 对比结果

| 项目 | agenty | TD Agent v0.4.0 | TD Agent v0.4.1 |
| --- | ---: | ---: | ---: |
| 直接运行时依赖 | 2 | 5 | 2 |
| 核心依赖 | `rich`、`questionary` | 另含 `aiohttp`、`pydantic`、`python-dotenv` | `rich`、`questionary` |
| 原生扩展 wheel | 无 | `pydantic-core` 等 | 无 |
| CLI wheel 大小 | — | 约 55 KB | 约 55 KB |

## 主要变化

| 类型 | 变化 | 用户价值 |
| --- | --- | --- |
| 加速 | 使用标准库 `urllib` 完成异步 LLM HTTP 请求 | 移除 `aiohttp` 及其传递依赖 |
| 加速 | 使用轻量 dataclass 表达内部 LLM 数据 | 移除 `pydantic` 和原生 `pydantic-core` wheel |
| 加速 | 内置项目所需的 `.env` 解析 | 移除 `python-dotenv` |
| 保持 | 继续从 GitHub Release 安装预构建 CLI wheel | 不需要 Git clone 或本地构建 |

## 安装

```bash
curl -fL --connect-timeout 10 --retry 3 --progress-bar \
  https://raw.githubusercontent.com/yukai08008/td-agent/v0.4.1/install.sh | bash
```

## 兼容性

- CLI、配置和持久化数据格式与 `v0.4.0` 兼容。
- LLM 请求仍保持异步接口；底层网络实现改为 Python 标准库。
