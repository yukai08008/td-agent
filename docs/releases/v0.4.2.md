# TD Agent v0.4.2 — 配置随 wheel 本地初始化

> 本版本移除安装后的 3 次 GitHub Raw 配置下载，使安装网络路径进一步接近 agenty。

## 主要变化

| 类型 | 变化 | 用户价值 |
| --- | --- | --- |
| 加速 | 模型注册表和环境模板直接打包进 wheel | 安装后无需再次访问 GitHub Raw |
| 加速 | `toe-dac config --init` 在本地创建缺失配置 | 初始化通常瞬间完成 |
| 保持 | 已存在的 `models.json`、`.env` 和 `.env.local` 不会被覆盖 | 升级不会破坏本机配置和密钥 |

## 安装实测

同一机器上的隔离安装结果：

| 场景 | agenty | TD Agent v0.4.2 | 说明 |
| --- | ---: | ---: | --- |
| 独立空 uv 缓存 | 25.31 秒 | 36.94 秒 | 都安装 8 个包；不同时间的公网解析波动明显 |
| 共享现有 uv 缓存 | 25.23 秒 | 16.44 秒 | TD Agent 直接使用 Release wheel，agenty 仍拉取并构建 Git 源码 |

`v0.4.2` 的配置初始化完全在本地完成，不再产生 3 次 GitHub Raw 请求。冷缓存剩余耗时来自 GitHub/PyPI 网络，而不是额外依赖或配置下载。

## 安装

```bash
curl -fL --connect-timeout 10 --retry 3 --progress-bar \
  https://raw.githubusercontent.com/yukai08008/td-agent/v0.4.2/install.sh | bash
```

## 兼容性

- CLI、配置和持久化数据格式与 `v0.4.1` 兼容。
- `config --init` 只创建缺失文件，不覆盖已有内容。
