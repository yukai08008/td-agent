# TD Agent v0.4.2 — 配置随 wheel 本地初始化

> 本版本移除安装后的 3 次 GitHub Raw 配置下载，使安装网络路径进一步接近 agenty。

## 主要变化

| 类型 | 变化 | 用户价值 |
| --- | --- | --- |
| 加速 | 模型注册表和环境模板直接打包进 wheel | 安装后无需再次访问 GitHub Raw |
| 加速 | `toe-dac config --init` 在本地创建缺失配置 | 初始化通常瞬间完成 |
| 保持 | 已存在的 `models.json`、`.env` 和 `.env.local` 不会被覆盖 | 升级不会破坏本机配置和密钥 |

## 冷缓存基线

同一机器、两个独立空 uv 缓存的 `v0.4.1` 前置对比：agenty 安装 8 个包，用时 25.31 秒；TD Agent 安装相同 8 个包并额外下载 3 个配置文件，用时 34.62 秒。`v0.4.2` 移除了后半段 3 次网络请求。

## 安装

```bash
curl -fL --connect-timeout 10 --retry 3 --progress-bar \
  https://raw.githubusercontent.com/yukai08008/td-agent/main/install.sh | bash
```

## 兼容性

- CLI、配置和持久化数据格式与 `v0.4.1` 兼容。
- `config --init` 只创建缺失文件，不覆盖已有内容。
