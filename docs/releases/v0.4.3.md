# TD Agent v0.4.3 — 可观察的包安装过程

> 本版本让用户在网络解析较慢时始终知道安装正在进行，而不是面对没有反馈的终端。

## 安装时显示

- 当前安装的 Release wheel 或 Git 来源。
- 核心运行时依赖和空缓存包数量。
- uv 缓存目录与工具安装目录。
- uv 原生的 `Resolved`、`Prepared`、`Installed` 和包清单。
- uv 尚未输出新阶段时，每 5 秒显示一次已用时间和当前可能进行的工作。

示例：

```text
[td-agent] Package source: ...toe_dac-0.4.3-py3-none-any.whl
[td-agent] Runtime dependencies: rich, questionary (8 packages on an empty cache).
[td-agent] uv cache: ~/.cache/uv
[td-agent] uv tools: ~/.local/share/uv/tools
[td-agent] uv is still working (10s): resolving metadata or downloading packages...
Resolved 8 packages in 12.4s
Prepared 1 package in 1.2s
Installed 8 packages in 14ms
```

## 详细诊断

需要查看 uv 完整内部日志时：

```bash
curl -fsSL https://raw.githubusercontent.com/yukai08008/td-agent/main/install.sh \
  | TD_AGENT_INSTALL_VERBOSE=true bash
```

## 兼容性

- 只改变安装展示，不改变 CLI、配置和持久化数据格式。
- uv 原生进度没有被关闭；详细模式使用官方的全局 `--verbose` 参数。
