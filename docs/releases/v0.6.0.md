# TD Agent v0.6.0 — 模型判断与确定性控制层协作

发布日期：2026-08-10

## 核心变化

- Target、Observe、Estimate、Decide、Act、Action Check、Target Check 均保留模型关键判断；
- Observe 由模型选择事实、来源和技能，运行时只机械执行工具并保存证据；
- 截图自动写入 canonical Session trace，控制层登记路径、哈希、大小、URL 和页面原始元数据；
- Action/Target Check 先计算硬事实，再由模型完成语义与整体覆盖审查；
- 删除证据复制、重复验收等机械 Action，阻止用户未提出的路径和数值限制成为硬约束；
- 预算内 Action/Check 恢复无需再次向用户请求授权；
- 模型网络流中断等运行错误进入结构化日志和自动恢复预算，不再直接导致 CLI 崩溃；
- `toe-dac run --mode live` 与交互式 CLI 使用相同的统一模型配置解析。

## 验证

- 全量自动化测试：137 项；
- 标准场景：`REG-001`；
- 真实模型开发复测保留成功与失败轨迹，详见 [benchmarks](../benchmarks/README.md)。
