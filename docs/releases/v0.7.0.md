# TD Agent v0.7.0 — 异常经验检索、采纳与效果闭环

发布日期：2026-08-10

## 核心变化

- 异常首次出现即保存结构化签名和来源引用；
- 每次自动修复拥有独立 Treatment，记录开始、成功或失败；
- `thread` 经验保持 User Thread 隔离，`system` 经验可安全跨 Thread 匹配；
- system 候选只向模型暴露去敏签名、统计和解决方案；
- 模型通过结构化 `experience_decisions` 明确 adopt/reject，控制层不自动采纳；
- 采纳经验后的实际执行结果更新 use/success/failure/effectiveness；
- Resolution 可关联修复版本、Git commit、回归测试、operation、evidence 和 Artifact；
- 新增 `toe-dac experience list/show/rebuild`。
