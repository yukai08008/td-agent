# TD Agent v0.8.0 — Guarded 状态机、多重边与受控执行

发布日期：2026-08-11

## 核心变化

- 状态机 Graph 升级为有向多重图，同一状态对可保留多个不同事件边；
- 修复 `recovering → failed` 的 `give_up` 被通用失败边覆盖的问题；
- 为 Target、Observe、Estimate、Decide、Act、Action Check、Target Check、人工等待和恢复路径增加 Guard；
- Guard 异常 fail-closed；钩子或转移失败时原子回滚 Context、State 和内存日志；
- 状态机引擎迁入 `toe_dac.state_machine`，消除本地 `andy_state` 同名包干扰；
- Skill 渐进加载支持受控异步命令执行，状态变化操作要求 before/action/after 证据；
- 每个 TOE-DAC 阶段自动保存阶段前缀原始证据，Web 证据保留截图和页面元数据；
- 模型 HTTP 层处理响应截断、连接中断和 SSL 超时，耗尽后不再重复执行整个阶段；
- CLI 展示模型调用、传输重试、技能调用和阶段耗时；
- 异常出现、处置、成功或失败继续写入经验闭环。

## 状态机安全边界

业务 Validator 负责检查输入结构和语义；Graph Guard 负责在转换瞬间检查 Context 不变量。两层职责不同，任何一层拒绝都不会推进状态。

## 验证

- 覆盖多重边保留、Guard 分支选择、Guard 拒绝、钩子失败原子回滚和 `give_up` 实际可达；
- 覆盖模型传输重试聚合及上层阶段不重复执行；
- 181 项自动化测试全部通过。
