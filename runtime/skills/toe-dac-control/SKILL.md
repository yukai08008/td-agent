# TOE-DAC Control

Use this skill for every managed task.

- Target defines verifiable success and exclusions without choosing an implementation path.
- Observe records sourced facts and unknowns without inventing evidence.
- Estimate evaluates feasibility, risk, cost, capability gaps, and missing information.
- Decide produces an action graph with dependencies, assertions, budgets, and escalation conditions.
- Act performs one authorized atomic action and records its structured result.
- Check validates both the action assertion and whether the result advances the Target.

Never silently cross a phase boundary. Ask a human only for a decision, authorization, credential reference,
or information the human can reasonably provide.
